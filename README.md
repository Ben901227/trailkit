# trailkit

**開啟工具 → https://ben901227.github.io/trailkit/**

在瀏覽器裡開啟、檢視、編輯與合併 GPX / KML / KMZ 軌跡，並像 Google Earth 一樣疊加
魯地圖與百年歷史地圖。檔案只在你的裝置上處理，不會上傳到任何伺服器。

---

## 使用說明

### 開啟檔案

- **電腦**：把檔案直接拖進畫面，或按左上角「開啟檔案」。可以一次拖多個。
- **手機**：按「開啟檔案」從檔案 App 選取。
- 支援 **GPX**、**KML**、**KMZ**、**GeoJSON**。格式是看檔案內容判斷的，副檔名不對也能開。
- 開過的檔案會自動記住，下次打開網頁會還原；按「關閉全部」即清除。

### 地圖操作

| 操作 | 動作 |
|---|---|
| 拖曳 | 平移 |
| 滾輪 / 雙指開合 | 縮放 |
| **Shift** 或 **⌘** + 拖曳（Windows 為 **Ctrl**） | 旋轉與傾斜視角，同 Google Earth |
| 雙指旋轉 | 旋轉與傾斜（觸控） |
| 點左下角羅盤 | 轉回正北 |

### 三個分頁

畫面左側（手機為下方可上滑的面板）分成三個分頁：

- **檔案** — 開啟的檔案清單。每個檔案可以展開看軌跡與航點，並有三顆按鈕：
  眼睛（整個檔案顯示／隱藏）、下載（只匯出這個檔案）、✕（關閉）。
  每一列軌跡或航點也能單獨開關、換顏色、縮放過去。
- **圖層** — 底圖、臺灣山頭、航點顯示、圖片疊圖，以及疊加圖層清單。
- **資訊** — 目前選取項目的詳細資料與編輯動作。

### 疊加圖層

在「圖層」分頁的「加入圖層」可以直接加入：

- **登山圖資**：魯地圖各版本、Happyman GPX 疊圖、林班界
- **百年歷史地圖**：中研院全套 21 張圖幅，1899 日治臺灣全圖到 2003 經建 4 版

每層可以調上下順序與不透明度（新加入預設 60%，看得到底下的地圖）。
匯入含圖層的 KML/KMZ 時，裡面的圖層也會自動加進同一份清單。

「臺灣山頭」是內建的 3,669 座山頭清單，**預設關閉**，在「圖層」分頁打開；
放大到一定程度會標出名稱與高程，點一下顯示詳細資料。

### 編輯軌跡

1. 先點選一條軌跡（在地圖上點，或在「檔案」分頁點）。
2. 按工具列的「編輯」進入編輯模式。
3. 這時可以：
   - **拖曳圓點** 移動該點
   - **點軌跡線** 在該處插入新點
   - **點圓點** 選取它，然後在「資訊」分頁刪除該點、從該點分割、或只保留前段／後段
   - 整條軌跡可以反轉方向、重新命名、刪除
4. 隨時用 **⌘Z** 復原、**⇧⌘Z** 重做。

> 點很密的軌跡（例如每半公尺一個點）要放大到看得清單點才會出現可拖曳的圓點，
> 否則畫面上會有上萬個把手，反而按不到。面板會告訴你需要放大。

### 合併軌跡

工具列（手機在「檔案」分頁）的「合併」：

- **合成一檔** — 把選取的軌跡收進同一個新檔案，各自維持獨立。
- **首尾相接** — 依清單順序串成單一軌跡。可以用上下箭頭排順序、用 → 反轉個別軌跡方向。
  按下去之前會顯示**最大接縫距離**，方便確認順序與方向對不對。

### 匯出

工具列的「匯出」，或檔案列上的下載按鈕。可選 GPX / KML / KMZ / GeoJSON，
以及匯出範圍（全部／僅顯示中／僅選取項目／僅這個檔案）。

### 3D 地形

工具列的「3D」切換傾斜的地形檢視。3D 是**瀏覽模式**，會離開編輯狀態——
在傾斜且貼合地形的畫面上拖點沒辦法拖得準。

## 手機、平板：裝成 App 用

trailkit 是 PWA，加到主畫面之後就跟一般 App 一樣：全螢幕、沒有網址列、
從桌面圖示直接開，操作起來比在瀏覽器分頁裡順很多。

**iPhone / iPad（Safari）**
1. 用 Safari 打開 https://ben901227.github.io/trailkit/
2. 點下方的「分享」按鈕
3. 選「加入主畫面」

**Android（Chrome）**
1. 用 Chrome 打開同一個網址
2. 點右上角「⋮」
3. 選「安裝應用程式」或「加到主畫面」

**離線**：App 本身、字型與山頭清單都會存在裝置上，沒有網路也打得開，
也能開啟本機的 GPX/KML 檔案。**地圖底圖需要網路**，離線時地圖會是空白的。

## 資料存在哪裡

一切都留在這台裝置的瀏覽器裡，不會上傳：

- **localStorage**：底圖與疊加圖層清單（含順序、不透明度）、山頭與航點的顯示設定。
- **IndexedDB**：目前開啟的檔案，含疊圖圖片的原始位元組。「關閉全部」會清空。

## 內建資料

- `public/data/peaks.json`：臺灣山頭清單（3,669 筆），整理自 Google Earth 版
  「魯地圖＋航跡圖」的全山頭圖層，重新編排為 `[名稱, 經度, 緯度, 高程?]`。
- `public/fonts/`：Noto Sans 的拉丁字範圍 SDF 字形（OFL-1.1）。

## 開發

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 解析、統計、編輯指令與匯出的單元測試
npm run build    # 型別檢查 + 產生 dist/
```

`test data/`（未進版控）可放實機匯出的檔案，`test/testdata.test.ts` 會整個資料夾跑過一遍，
確認每個檔案都開得起來且沒有內容被略過；資料夾不存在時該測試自動跳過。

## 部署

推到 `main` 後由 `.github/workflows/deploy.yml` 自動建置並發佈到 GitHub Pages。
Vite 的 `base` 設為 `./`，因此同一份建置在網域根目錄與 `/<repo>/` 子路徑下都能運作。

## 底圖來源

預設底圖使用免金鑰的公開圖磚。**OpenStreetMap 官方圖磚有使用政策限制**，正式對外站台請在
`src/map/basemaps.ts` 換成自己的圖磚服務，或在介面上使用「自訂圖磚網址」。
魯地圖與中研院百年歷史地圖為第三方服務，本工具僅引用其公開圖磚網址。
